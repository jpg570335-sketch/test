LAST CHAMBER — Canvas + WebRTC, Node.js 없음

- 게임 테이블과 전투 상태의 시각화는 HTML5 Canvas 2D API로 그립니다.
- UI 조작 버튼 및 연결 신호 입력은 HTML 컨트롤을 사용합니다.
- Node.js/npm/별도 게임 서버 프로그램은 필요하지 않습니다.
- 두 플레이어 모두 index.html을 엽니다.
- 호스트가 방 만들기 → 신호 복사/전달 → 게스트가 신호 붙여넣고 방 참가 준비
  → 게스트 답변 신호를 호스트에게 전달 → 호스트가 답변 신호 적용.
- 신호 교환은 메신저로 수동 복사/붙여넣기 합니다.
- WebRTC는 일부 브라우저에서 file:// 실행이 제한될 수 있습니다. HTTPS에서 실행하는 것이 더 안정적입니다.
- STUN만 사용하므로 학교 Wi-Fi/방화벽/NAT 환경에서는 연결 실패가 발생할 수 있습니다.
