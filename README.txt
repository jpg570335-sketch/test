LAST CHAMBER — Canvas + WebRTC, Node.js 없음

- 게임 테이블과 전투 상태의 시각화는 HTML5 Canvas 2D API로 그립니다.
- UI 조작 버튼 및 연결 신호 입력은 HTML 컨트롤을 사용합니다.
- Node.js/npm/별도 게임 서버 프로그램은 필요하지 않습니다.
- 두 플레이어 모두 index.html을 엽니다.
- 호스트가 방 만들기 → 신호 복사/전달 → 게스트가 신호 붙여넣고 방 참가 준비
  → 게스트 답변 신호를 호스트에게 전달 → 호스트가 답변 신호 적용.
- 신호 교환은 메신저로 수동 복사/붙여넣기 합니다.
- WebRTC는 일부 브라우저에서 file:// 실행이 제한될 수 있습니다. HTTPS에서 실행하는 것이 더 안정적입니다.
- STUN만 사용하므로 학교 Wi-Fi/방화벽/NAT 환경에서는 연결 실패가 발생할 수 있습니다.


[신호 적용 오류 수정]
- 호스트가 이미 적용한 answer를 다시 적용하지 않도록 상태를 확인합니다.
- 호스트/게스트가 잘못된 종류의 신호를 적용하면 안내 메시지를 표시합니다.
- 연결 절차 안내를 명확하게 수정했습니다.
- 연결 오류가 계속되면 양쪽 모두 페이지를 새로고침하고 새 신호로 처음부터 다시 연결하세요.


[모바일 및 AI 모드]
- 모바일 화면에 맞춘 반응형 스타일과 큰 터치 버튼을 추가했습니다.
- '혼자 플레이 · AI 상대'에서 난이도를 고르고 AI와 시작을 누르면 로컬 AI 대전을 시작합니다.
- AI 모드는 인터넷 연결 없이도 작동합니다. 온라인 2인 대전은 기존 WebRTC 연결 방식을 사용합니다.
- 모바일에서 열 때는 최신 Chrome/Safari를 권장합니다. 파일을 직접 여는 환경에서 브라우저가 기능을 제한하면 HTTPS 정적 호스팅을 이용하세요.


[UI 다듬기]
- 과한 광택과 균일한 강조를 줄이고, 낡은 황동/짙은 목재 테이블을 연상시키는 색과 질감을 적용했습니다.
- 버튼의 눌림 반응, 얇은 테두리, 미세한 표면 질감과 모바일 간격을 다듬었습니다.
- 게임 로직과 Canvas 기반 테이블 표현은 유지했습니다.


[사용자 제공 규칙 + 3D 연출 버전]
- 요청한 기본 규칙을 반영했습니다: 플레이어 선턴, 실탄/공포탄, 자신에게 공포탄 발사 시 턴 유지, 라운드 1~2의 1회 부활, 3라운드 부활 없음.
- 요청한 9개 아이템 이름과 효과를 구현했습니다. 아이템 사용 시 별도 3D 스타일 모션 오버레이가 재생됩니다.
- Canvas 테이블에 깊이감과 그림자를 더하고 CSS 3D transform/애니메이션을 추가했습니다. 이는 완전한 3D 모델 기반 엔진이 아니라 Canvas + CSS 3D 연출입니다.
- 모바일 반응형 UI와 AI 대전은 유지했습니다.
